# Community bei Stream Hub

GitHub Discussions ist für Ideen, allgemeine Fragen und Umfragen gedacht. GitHub Issues sind für reproduzierbare Fehler und klar beschriebene Feature-Wünsche da.

Bitte veröffentliche keine Passwörter, Cookies, E-Mail-Adressen, Zahlungsdaten, Gerätekennungen oder privaten Screenshots. Anbieter-Konten bleiben privat; poste niemals Anmeldedaten oder Sitzungsinformationen.

Der Community-Bereich wird vom Projektinhaber moderiert. Vorschläge können kommentiert, markiert, priorisiert, geschlossen oder in eine spätere Aufgabe umgewandelt werden. Ein Vorschlag ist keine Zusage, dass die Funktion umgesetzt wird. Der Feed ist asynchron; Live-Chat oder garantierte Antwortzeiten gibt es nicht.

Respektvoller Umgang ist Voraussetzung. Spam, persönliche Angriffe, unzulässige Inhalte und Inhalte, die Zugangsdaten oder Rechte Dritter gefährden, können entfernt oder gesperrt werden.
