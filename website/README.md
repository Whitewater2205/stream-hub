# Stream Hub Download-Seite

Statische deutsche Landingpage für den Windows-Prototyp. Sie kann auf einem beliebigen statischen Webhost bereitgestellt werden.

## Lokale Vorschau

Im Ordner `website` einen statischen Dateiserver starten und `index.html` öffnen. Der Download-Button verweist auf `downloads/Stream-Hub-Windows-x64.zip`.

## Veröffentlichungsstand

- Enthält einen ZIP-Build der Windows-x64-App.
- Noch nicht online veröffentlicht.
- Keine Nutzerkonten, Tracker oder Server-APIs.
- Vor einer öffentlichen Veröffentlichung müssen Hosting, Verteilung und Lizenztext vom Betreiber bestätigt werden.
